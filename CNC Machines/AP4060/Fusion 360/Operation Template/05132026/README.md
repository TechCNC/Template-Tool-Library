# Operation Templates — AP4060 — 05132026

## Contents

- `Templates_AP4060_05132026.zip` — 63 Fusion 360 operation templates (`.f3dhsm-template`)

## Description

All 63 templates have been **validated in production on the TechCNC AP4060 CNC router**. Each template carries a tri-lingual description (English / Français / Русский) covering validation status, conditions of use, and a liability disclaimer.

Filename suffix `xN` indicates how many identical operations were consolidated into that template (e.g. `2D Contour D8 BB 8x8x24 (cell-37) x41` represents 41 identical operations).

## How to import

1. Unzip the archive
2. In Fusion 360 Manufacture: **Manage → Templates → right-click target folder → Import**
3. Select all `.f3dhsm-template` files

Recommended target folder in Fusion: `user://AP4060_new`
